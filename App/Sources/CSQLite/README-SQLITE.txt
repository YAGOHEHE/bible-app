SQLite amalgamation 3.54.1 (sqlite-amalgamation-3540100.zip from https://www.sqlite.org/2026/).
SQLite is in the public domain (https://www.sqlite.org/copyright.html): no license conditions.
Bundled because macOS 10.13 ships SQLite 3.19 (no FTS5 trigram tokenizer, no UPSERT).
Build flags are in App/Package.swift (SQLITE_ENABLE_FTS5, JSON1, THREADSAFE=1, ...).
